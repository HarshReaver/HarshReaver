## Projects

### [Loan Approval Predictor](https://github.com/HarshReaver/Loan-Approval-Predictor)

A supervised ML project that predicts whether a loan application should be approved or rejected based on applicant data.

The notebook goes through the complete pipeline — EDA, missing value handling, feature encoding, training and comparing five classifiers, and interpreting results via confusion matrices and feature importance plots. The goal was less about hitting a metric and more about understanding what each step actually does and why model choices matter.

`Python` `Scikit-learn` `Pandas` `Matplotlib` `SVM` `Random Forest` `XGBoost` `Jupyter`

### [Dynamic-RRF](https://github.com/HarshReaver/VA-RRF)
